# Parley — privacy policy

This repository exists for one reason: to publish the privacy policy for **Parley**, a Chrome
extension that translates web pages on your own device, at a public URL that the Chrome Web Store
can link to.

The policy is [`index.html`](index.html), served at
<https://prokashif.github.io/parley-privacy/>.

The extension's source code lives in a separate, private repository. Nothing in this repository is
part of the extension itself.

Short version of the policy: Parley collects nothing, transmits nothing, and has no server to
transmit to. Translation runs against the model built into Chrome, on your machine.
