Parley — Privacy Policy

Last updated 11 November 2026

Parley does not collect, transmit, store or sell any personal information. It makes no network requests of its own, contains no analytics, no trackers and no remote code, and has no backend server to send anything to.

How translation works

Parley uses the Translator API built into Google Chrome. Translation runs on your own computer, against a language model that Chrome downloads and manages itself. The text of the pages you translate is passed to that local API and never leaves your device. Parley has no servers, no account system and no API keys.

The one-off download of a language model is performed by Chrome, not by Parley, and is governed by Google's privacy policy.

What is stored, and where

Parley keeps a small amount of configuration using Chrome's extension storage:

ItemPurpose
Preferred languageSo the right target is selected next time.
Last three languages usedShown at the top of the language list.
Two on/off settingsWhether to translate attributes, and content that loads in later.

That is the complete list. It contains no page content, no browsing history and nothing that identifies you. It is written with chrome.storage.sync, so if you have Chrome Sync switched on, Chrome itself may sync those few values across your own signed-in devices. That transfer is between you and Google; the author of Parley cannot see it.

The original text of a translated page is held in memory only, so the Original button can put it back. It is discarded as soon as you restore the page, close the tab or reload it.

Permissions

PermissionWhy it is needed
activeTabRead and rewrite the text of the tab you are on, and only when you click Parley.
scriptingInsert the script that walks the page's text and writes translations back.
storageRemember the handful of settings listed above.
contextMenusAdd the "Translate this page" right-click entry.
<all_urls> (optional)Only requested if you switch on Embedded frames, because a frame from another site is outside the access activeTab grants. Switching it off removes the permission.

Parley has no access to any page until you click it, and no background access to your browsing at all.

Children

Parley collects no data from anyone, including children under 13.
